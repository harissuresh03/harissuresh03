## Featured Projects
 
### 🧠 Lumora — Smart Mental Health Monitoring System
AI-powered full-stack platform giving students, counsellors and parents role-based dashboards for mood tracking, journaling and validated clinical assessments (PHQ-9, GAD-7, PSS-10).
 
**Key features**
- Conversational AI companion and sentiment-based mood detection (Groq API, LLaMA 3.3 70B)
- 7-day academic stress forecasting and automated crisis alerts
- Hybrid MySQL + Firebase Firestore architecture for relational and real-time data
- Automated PDF wellness reports for counsellors
**Tech:** React, Node.js/Express, MySQL, Firebase Firestore, Groq API
